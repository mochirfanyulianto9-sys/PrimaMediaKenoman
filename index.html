Panduan Koneksi MikroTik via IP Public / DDNS

1. Mode Cepat (Live NOC) vs REST API v7 (Direct):

Gunakan Mode Cepat (Live NOC) untuk langsung terhubung cepat dengan simulasi telemetry real-time PPPoE, Ethernet & FTTH. Jika MikroTik Anda menggunakan RouterOS v7.1+ dan sudah mengaktifkan HTTPS/REST API, pilih REST API v7 (Direct).

2. Perintah Terminal MikroTik untuk REST API (RouterOS v7):

/ip service set www-ssl disabled=no port=443
/ip cloud set ddns-enabled=yes
/ip firewall filter add chain=input protocol=tcp dst-port=443,8728 action=accept comment="Allow NOC Prima Media"
